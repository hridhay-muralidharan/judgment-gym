# Curated Demo Scenario Journey

The public MVP uses five original, secular reflection prompts. They support one coherent self-awareness journey rather than unrelated journaling exercises.

## Sequence

1. **Baseline** — establish a first tentative thread through a clear, moderately consequential situation.
2. **Changed condition** — change one major variable such as personal cost, time pressure, information, relationship, or consequence.
3. **Role reversal** — change who holds responsibility or who bears the consequences.
4. **Tension** — place two observed considerations into conflict without resolving them.
5. **Transfer or user-authored** — apply an emerging thread in a new domain or let the user provide a meaningful situation.

## Scenario metadata

Each scenario records its source trajectory, purpose, change from the previous scenario, expected profile effect, target frontend state, and generation strategy.

## Source handling

Prompts should be original, culturally inclusive, non-leading, and reviewed for psychological safety. Do not claim to reproduce a person's mind, diagnose a user, or impose a worldview.

## Demo outcome

The judge should see:

```text
Prompt → reflection → tentative interpretation → correction
→ changed condition → perspective shift → unresolved tension
→ bring-forward question → self-awareness map → export/reset
```
