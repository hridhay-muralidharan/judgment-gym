# A professional journey as a faculty-development model

The long-form professional account supplied for therapist review is not part of this public repository. This document defines how such an account should be represented when the user supplies it privately to the app.

## The model should show movement across contexts

The output should not be a personality profile or a polished autobiography. It should be an evidence-linked map of episodes and possible changes across time.

Each period should contain:

- context and role;
- important situation or transition;
- what the person noticed;
- body and emotion;
- thoughts and interpretations;
- what they said and did;
- what they wanted or were protecting;
- consequence;
- later re-interpretation;
- faculties involved;
- evidence and uncertainty.

## Useful hypotheses to test against the account

The model may examine whether the account contains changes in:

- external expectation versus self-endorsed direction;
- status, belonging, mastery, contribution, and security as motives;
- threat sensitivity under financial or interpersonal pressure;
- avoidance, persistence, help-seeking, and repair;
- independent judgment and self-management;
- ability to learn from feedback;
- role and culture fit;
- systems thinking and practical agency;
- integration of personal experience with future work direction.

These are dimensions for inquiry, not conclusions about the person. Every dimension must point back to episodes and remain editable.

## Input configurations and output shape

The long-form map uses one text box with three configurations:

- **One event:** examine one episode in detail.
- **One situation:** examine several events within one relationship, role, transition, or context.
- **Several situations:** compare different contexts across time and look for possible changes.

The configuration changes how the model groups and compares the account. It does not change the user's control over the source text or the provisional status of the output.

The generated model should have four views:

1. **Timeline** — the situations and transitions in sequence.
2. **Faculty map** — which faculties appear in which contexts.
3. **Evolution** — what seems to have changed, strengthened, narrowed, or remained unresolved.
4. **Open questions** — interpretations that need the user's correction or a therapist's perspective.

The interview narrative is a separate transformation of this model. It should be concise, truthful, and edited by the user. It should never become the canonical version of the person's life.
